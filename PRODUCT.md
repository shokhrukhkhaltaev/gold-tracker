# Gold Tracker — Продуктовое описание

## Суть продукта

**Gold Tracker** — веб-приложение, которое собирает актуальные цены на золотые слитки в банках Узбекистана и показывает, где и по какой цене можно их купить прямо сейчас.

Данные берутся с официального сайта Центрального банка Узбекистана (ЦБУ) и обновляются дважды в день — в 09:00 и 17:00 по Ташкентскому времени.

---

## Проблема

Гражданин или инвестор, который хочет купить золотые слитки в Узбекистане, сталкивается с рядом неудобств:

- Нет единого места с актуальными ценами — нужно обходить сайты разных банков
- На сайте ЦБУ данные представлены в виде сложной таблицы, неудобной для чтения
- Непонятно, в каких именно отделениях есть нужный вес в наличии
- Нет истории цен — невозможно отследить тренд
- Нет уведомлений об изменениях

Gold Tracker решает всё это в одном интерфейсе.

## Ключевые возможности

### 1. Актуальные цены на слитки
Цены на 5 весовых категорий: **5g, 10g, 20g, 50g, 100g** — в сумах (UZS).
Для каждого веса отображается:
- Текущая цена
- Тренд (выше/ниже/без изменений относительно предыдущего обновления)
- Кнопка перехода к банкам, где данный вес в наличии

### 2. Доступность по банкам и городам
Список банков с фильтрацией по:
- **Весу слитка** — показывает только банки с нужным слитком
- **Городу** — Ташкент, Самарканд, Бухара и другие

По каждому банку:
- Название и краткое обозначение
- Количество отделений с наличием
- Список отделений с адресом, городом, количеством и телефоном

### 3. История цен (15 дней)
Столбчатая диаграмма за последние 15 дней для каждого веса.
Показывает:
- Минимальную и максимальную цену за период
- Подсказки при наведении (конкретная дата и цена)

### 4. Избранные банки
Пользователь может добавить банк в избранное нажатием на звезду (⭐) в карточке банка.
- Избранные банки всегда отображаются **вверху списка** в отдельной секции "Избранное"
- Настройка сохраняется в `localStorage` — не сбрасывается при перезагрузке
- Снять из избранного — повторное нажатие на звезду
- Типичный сценарий: пользователь знает, что обычно берёт золото в одном банке, и хочет сразу видеть его наличие без прокрутки

### 5. Telegram-бот
Бот отправляет ежедневную сводку с актуальными ценами в 11:00 по Ташкенту.
Поддерживает команды:
- `/prices` — цены прямо сейчас
- `/nalichie` — наличие по городу (выбор через кнопки)
- `/start` — приветствие и инструкция

## Пользовательский сценарий

```
Пользователь хочет купить золотой слиток 10g в Самарканде

1. Открывает Gold Tracker → видит текущую цену 10g
2. Нажимает "Проверить наличие" → переходит на страницу банков
3. Выбирает вес 10g и город Самарканд
4. Видит 2 банка с наличием → нажимает на карточку
5. В модалке — адреса отделений, количество, телефон
6. Звонит или приходит в отделение
```

## Интерфейс

**Страница "Цены"** (`/`)
- Карточки по каждому весу (цена, тренд, кнопка)
- График за 15 дней

**Страница "Банки"** (`/banks`)
- Фильтры: вес (чипы) + город (дропдаун)
- Карточки банков с иницалами и количеством доступных отделений
- Модальное окно с деталями отделений

**Навигация**: Нижний бар с двумя разделами — Цены / Банки

**Дизайн**: Material 3, основной цвет — золотой (#705d00), шрифт Manrope, мобильно-ориентированный.

## Ограничения текущей версии

1. **Телефоны отделений** — сгенерированы как демо-данные, не реальные
2. **Настройки Telegram** — сбрасываются при перезапуске сервера (нет постоянного хранилища)
3. **Парсер ЦБУ** — зависит от структуры сайта; при редизайне ЦБУ потребуется обновление
4. **Нет авторизации** — публичный API, данные открыты для всех
5. **Один сервер** — не масштабируется горизонтально
